Entry for the make.fun bounty **"Till Firmware Do Us Part"** (slug `u-azazex-till-firmware-do-us-part-32172929`).

## The entry

`main.ts` is a small Node.js program (standard library only) that writes a single
one-line wedding vow spoken by a robot at its own wedding to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

The vow is a machine's promise in its own language: 99.9% uptime, a sliver of
time kept back for recharging beside the one it loves, and a choice made anew
every morning — funny because it is a service-level promise at an altar, and
tender because underneath the uptime math it is still a vow to keep choosing
the same person, till firmware do us part.

## Run it

```sh
node main.ts
```
